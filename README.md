# 莘藝科技工程施工回報站

給現場施工人員用手機回報工作進度與照片，主管在後台查詢、審核與匯出歷史資料的網站。

## 功能

### 人員與權限
- 帳號密碼登入；新帳號與被重設密碼的帳號，首次登入時必須自行變更密碼
- **角色可自訂**：預設有「系統管理員」、「主管」、「員工」，可新增任意角色（例如「稽核」、「外包」）
- **每個角色可勾選能使用的功能**（權限矩陣一覽）
- 一個人可同時擁有多個角色；可以從「人員」頁指派角色，也可以從「角色」頁把人放入角色
- 帳號停用後立即無法登入
- 防呆：系統至少保留一位啟用中的系統管理員

| 權限 | 說明 |
|---|---|
| 新增工作回報 | 建立新工作 |
| 查看自己參與的工作 | 自己回報或被列為施工人員的工作 |
| 編輯自己參與的工作 | 修改內容、補傳照片；主管審核通過後鎖定 |
| 查詢所有人的工作歷史資料 | 後台查詢 |
| 編輯所有工作 | 包含已審核的工作 |
| 審核工作回報 | 核可 / 退回（退回需填意見） |
| 刪除工作與照片 | |
| 匯出工作資料 | CSV，可直接用 Excel 開啟 |
| 工作類別管理 / 人員帳號管理 / 角色與權限設定 | 後台管理 |

### 工作回報
- 自動產生工作單號（`SY20261023-001`）
- 欄位：工作類別、工作名稱、工作簡述、施工地址（可一鍵記錄 GPS 定位）、客戶 / 業主、現場聯絡人與電話、施工日期與起訖時間、施工人員（可複選）、進度狀態、使用材料 / 設備、異常狀況 / 待辦、備註
- 照片分為 **施工前 / 施工中 / 施工後**，可直接拍照或從相簿選取，上傳前在手機端自動壓縮，並顯示上傳進度；之後可隨時補傳
- 進度狀態：待施工、施工中、已完工、暫停、取消（一鍵切換）
- 主管審核：待審核、已核可、退回；被退回的工作修改後自動回到待審核
- 每筆工作都有完整的異動紀錄（誰在何時改了什麼）
- 工作頁可列印

### 後台查詢
- 依關鍵字、類別、進度、審核狀態、人員、施工日期區間查詢
- 首頁統計：今日施工、施工中、完工待審核、退回待修正
- 依查詢條件匯出 CSV

## 技術架構
- Node.js 20 以上、Express 5、EJS 伺服器端渲染（不需另外建置前端）
- SQLite（better-sqlite3）：單一檔案資料庫，不需另外架設資料庫
- 照片存放在 `data/uploads/`，只有具查看權限的人能透過網址取得
- 安全性：bcrypt 密碼雜湊、CSRF 防護、登入失敗次數限制、Session 存在資料庫、CSV 公式注入防護

## 本機執行

```bash
npm install
npm start            # http://localhost:3000
```

首次啟動會建立管理員帳號 **admin / admin1234**，登入後會要求立即變更密碼。

執行測試：`npm test`

## 部署到 Render（最快，可直接用手機開啟）

倉庫已附 `render.yaml`：
1. 用 GitHub 帳號登入 https://render.com
2. 點 **New → Blueprint**，選擇 `ibox` 倉庫
3. 依提示輸入 `ADMIN_PASSWORD`（admin 的初始密碼），按 **Apply**
4. 約 3–5 分鐘後會得到 `https://xxxx.onrender.com` 網址，用 `admin` 和剛才的密碼登入

> 預設為**免費方案，僅供試用**：閒置 15 分鐘會休眠，且**重新部署或重啟後資料與照片會清空**。
> 正式使用請依 `render.yaml` 檔頭說明改為 starter 方案並加上永久磁碟。

## 部署（Docker）

```bash
ADMIN_PASSWORD='請改成強密碼' docker compose up -d --build
```

資料（資料庫與照片）都在 `./data` 目錄，**請定期備份這個目錄**。

正式上線建議在前面加上 Nginx 或 Caddy 提供 HTTPS，並設定：

| 環境變數 | 說明 | 預設 |
|---|---|---|
| `PORT` | 服務埠號 | `3000` |
| `DATA_DIR` | 資料庫與照片存放位置 | `./data` |
| `ADMIN_PASSWORD` | 首次啟動時 admin 的密碼 | `admin1234` |
| `SESSION_SECRET` | Session 簽章金鑰（未設定時自動產生並存於 data 目錄） | 自動 |
| `COOKIE_SECURE` | 使用 HTTPS 時設為 `true` | `false` |
| `TRUST_PROXY` | 在反向代理後方時設為 `true` 或代理 IP | 不設定 |

## 目錄結構

```
server.js              進入點
src/app.js             Express 設定
src/db.js              資料表結構與初始資料
src/permissions.js     權限清單（新增功能時在此加權限代碼）
src/routes/            auth（登入）、jobs（工作回報）、admin（人員、角色、類別）
views/                 EJS 頁面
public/                CSS 與前端 JS（照片壓縮、上傳進度、GPS）
test/                  整合測試
```
